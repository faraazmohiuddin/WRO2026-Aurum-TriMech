# Quick GitHub Upload Guide

1. Create a new **public** GitHub repository.
2. Do not initialise it with extra files if you want the cleanest upload.
3. Extract this ZIP.
4. Open the repository's **Add file → Upload files** page.
5. Drag the extracted repository contents into GitHub.
6. Commit the upload.
7. Open the repository home page and confirm the README renders correctly.
8. Copy the public repository URL for submission.
9. Continue improving the same repository after submission.

Before uploading, replace any TODO that you can confirm immediately. Unconfirmed facts should remain TODO rather than being guessed.

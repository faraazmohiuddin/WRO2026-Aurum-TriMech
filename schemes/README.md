# Schemes and Wiring

Add the final electromechanical schematic here once the vehicle wiring is frozen.

Current Uno concept:
- TB6612FNG: PWMA D5, AIN1 D7, AIN2 D8, STBY D4
- Steering servo signal: D9
- HC-SR04: TRIG D10, ECHO D11
- MPU6050: SDA A4, SCL A5

Power wiring must be documented separately from signal wiring, with common ground clearly shown.
